# Engineer-bots

Discord 봇 프로젝트들을 한곳에서 개발하고 운영하기 위한 오거나이제이션입니다.

## About

여러 개의 Discord 봇을 개별 저장소로 흩어놓지 않고, 하나의 오거나이제이션 아래서
공통된 개발 방식과 운영 기준으로 관리합니다. 각 봇은 독립된 저장소로 존재하지만,
설계 원칙과 배포 흐름은 이 오거나이제이션 전체에서 일관되게 유지됩니다.

## What we build

- 서버 운영을 돕는 유틸리티 봇
- 특정 목적에 맞춘 기능형 봇
- 봇 간에 재사용 가능한 공통 모듈/라이브러리

## How we work

- 저장소마다 독립적으로 개발하되, 구조와 컨벤션은 통일합니다.
- 봇의 안정적인 운영(에러 처리, 로깅, 배포)을 최우선으로 합니다.
- 기능 추가보다 유지보수 가능한 코드를 우선합니다.

## Repositories

각 봇 프로젝트는 이 오거나이제이션의 저장소 목록에서 확인할 수 있습니다.
